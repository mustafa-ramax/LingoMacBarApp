# LingoMacBar README Assets

This directory contains the real LingoMacBar screenshots used by the repository README.

## Included assets

| Filename | Purpose |
|---|---|
| `lingomacbar-translation.webp` | Main LingoMacBar translation view |
| `lingomacbar-dark.webp` | LingoMacBar translation view in dark mode |

## Screenshot recommendations

When adding future screenshots:

- Prefer WebP or PNG with readable text.
- Crop unnecessary desktop space when it does not add context.
- Do not expose private conversations or translated content.
- Keep screenshot widths reasonably consistent.
- Use the real LingoMacBar interface rather than generic mockups.
- Write descriptive alt text in `README.md` so screenshots remain useful for accessibility and search context.
