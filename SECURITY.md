# Security Policy

Thank you for helping keep LingoMacBar users safe.

LingoMacBar is a **closed-source macOS application**. This public repository contains product documentation and support resources; it does not contain the application source code.

## Reporting a vulnerability

**Please do not report security vulnerabilities through a public GitHub issue.**

Instead, contact the developer privately through:

https://mustafaramx.com/#contact

Please include, where possible:

- a clear description of the issue
- the affected LingoMacBar version
- your macOS version
- steps required to reproduce the issue
- the potential security impact
- screenshots, logs, or proof-of-concept details that do not expose private information

## Please avoid including

Do not send or publish:

- passwords
- API keys or access tokens
- private account information
- confidential translated text that is not necessary to reproduce the issue
- third-party credentials

## Third-party translation providers

LingoMacBar uses Google Translate and DeepL as translation providers.

A vulnerability in Google, DeepL, WebKit, macOS, or another third-party component may need to be reported to the relevant vendor as well.

If you are unsure whether an issue is specific to LingoMacBar, you may still report it privately and describe the behaviour you observed.

Thank you for reporting security problems responsibly.
